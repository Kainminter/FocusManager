**DESCRIPTION:**

The FocusManager addon adds a border around your FFXI window. It will be yellow if the window is active, and grey if it is inactive.

This makes it easier to tell which window you are currently on.  

It will also enable BGM on the active window, muting BGM on the inactive windows.

**KNOWN ISSUES:**

Requires Send addon also to send mute request to other windows.

BGM enable / mute request will not work if you are in cetain menus or selections. 

**INSTRUCTIONS:**

In the windower console;

lua l FocusManager -- Loads the addon

lua u FocusManager -- Unloads the addon

fm border on/off -- Turns the border on or off

fm bgm on/off -- Turns the BGM toggling on or off
